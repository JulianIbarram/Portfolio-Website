Two-Tier Client-Server Application

Designed and implemented a two-tier client-server application using Java and MySQL, enabling secure execution of dynamic SQL commands through a GUI interface.

Designed and developed a two-tier client-server application using Java, creating a desktop GUI that allows users to securely interact with a MySQL database.

Implemented JDBC connectivity to enable seamless communication between the client application and the database, supporting the execution of 50+ dynamic SQL commands, including both DDL (schema creation/modification) and DML (data manipulation) operations.

Engineered secure authentication mechanisms to validate user credentials before granting access, ensuring that only authorized users could execute database queries.

Built a multi-user architecture with role-based access control, supporting four distinct roles (root, two client users, and an accountant), each with clearly defined permission levels.

Configured access restrictions using external properties files, allowing flexible management of user credentials and privileges without modifying core application code.

Developed backend logic to process incoming SQL queries, handle exceptions, and return accurate results to the front end in real time, ensuring a responsive and reliable user experience.

Implemented dynamic result rendering within the GUI, allowing users to view query outputs in structured formats immediately after execution.

Created a logging system to track and store 100+ database interactions, improving transparency, debugging capability, and auditability across concurrent user sessions.

Ensured stability and performance when handling multiple users simultaneously, demonstrating strong understanding of database integration, client-server architecture, and concurrent system design.
