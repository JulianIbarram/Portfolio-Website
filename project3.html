Multi-Level Database Management System Website

Developed a multi-level database management system website that enables users to securely interact with structured data through a web interface, integrating front-end design with backend database functionality.

Designed and deployed a multi-level database management system website using MySQL Workbench and Apache Tomcat, enabling users to interact with a relational database through an HTML/JSP-based interface.

Developed a secure login system that authenticates users and routes them to role-specific dashboards, ensuring a structured and controlled user experience.

Implemented role-based access control across multiple account types, including root, client, accountant, and data entry users, each with clearly defined permissions and capabilities.

Enabled root users to perform full database administration tasks, including creating, updating, and deleting records across all tables.

Configured client users with read-only access, allowing them to safely view database content without risking unintended modifications.

Built functionality for accountant users to specifically access and review order-related data, supporting financial tracking and reporting needs.

Designed data entry user capabilities to create and manage order records, ensuring accurate and efficient data input into the system.

Integrated JSP with backend database operations to dynamically process user requests, execute SQL queries, and render results in real time.

Ensured smooth communication between the web server and database, demonstrating strong understanding of web application architecture, database integration, and multi-user system design.
